# Templates

This folder contains reusable documentation templates for the Yunis project.

Use these templates when creating or updating documentation for agents, APIs, components, database tables, decisions, features, PRDs, or implementation tasks.

## Available Templates

- agent-template.md
- api-template.md
- component-template.md
- database-template.md
- decision-template.md
- feature-template.md
- prd-template.md
- task-template.md
