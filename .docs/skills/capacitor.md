# Capacitor Skill

## Purpose

Defines how Eternal Bond is packaged as a mobile application.

---

# Responsibilities

Capacitor provides:

- Android build
- iOS build
- Native APIs
- App Store deployment

---

# Principles

- Web-first.
- Native when necessary.
- One codebase.
- Consistent experience.

---

# Native Features

Use Capacitor plugins for:

- Push Notifications
- Camera
- File Access
- Share
- Deep Links

---

# Rules

Business logic must remain inside the shared application.

Avoid platform-specific implementations unless required.
