Examples:

- Friends
- Couples
- Families

- Best friends
- Roommates
- Siblings

## User Motivations

Users join Eternal Bond to:

- Stay close.
- Create memories.
- Chat.
- Complete challenges.
- Celebrate milestones.
- Receive AI guidance.
- Preserve relationship history.
- Build stronger emotional connections.

- Swipe culture.
